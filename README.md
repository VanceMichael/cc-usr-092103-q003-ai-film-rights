# AI影视素材权利链后台

面向运营发布环节的素材权利台账与发布闸门。学生作品送入**嘉年华展映、就业对接、商业推广或孵化路演**前，必须有且仅有一份作品能逐层追溯 **AI 演员、音乐、训练素材、实拍片段及全部派生版本**，并确认每份许可的**主体、用途、地域、期限、撤回条件**仍适用于目标渠道，闸门才放行。

## 覆盖范围

资料覆盖 2026 春季创作营：**84 名学生、33 支跨专业团队**（18 支三人队 + 15 支两人队），贯穿五个课程阶段：

| 阶段 | key | 权利关注点 |
| --- | --- | --- |
| AI创作培训 | `training` | 训练素材、平台教育版条款基线 |
| 城市命题创作 | `city_brief` | 实拍/配乐/AI演员逐项声明，并行修订分支 |
| 盲评 | `blind_review` | 匿名：不得出现院校、作者身份信息 |
| 城市嘉年华展映 | `showcase` | 非商业展映五要素复核 |
| 创业孵化 | `incubation` | 路演、招聘、商业推广按渠道再核对 |

## 资料契约与数据

- `contracts/program.schema.json` — 学生、团队、阶段、渠道、奖项契约
- `contracts/registry.schema.json` — 作品、版本（含多父合并）、素材、模型、许可声明、撤回、上传、盲评提交契约
- `fixtures/program.json` / `fixtures/registry.json` — 确定性生成的全量虚构数据（评估基准日 2026-09-22）
- `scripts/generate-fixtures.mjs` — 数据生成器（`npm run generate`）

每条许可声明（claim）固定五要素：`licensor`（主体）、`purposes`（用途）、`regions`（地域）、`term_start/term_end`（期限）、`revocable + revocation_conditions`（撤回条件），并记录权利依据（课堂协议、平台条款快照、曲库授权书、数据集许可）。

派生关系分两层：

1. **版本链**：`v-xx-01 培训练习 → 02 城市命题 → 03 盲评送选 → 04 展映发布`，并行修订通过多父版本合并（如 `v-06-04` 的父版本含分支 `v-06-03b`）。
2. **素材级派生**：训练素材 → AI演员 → 生成镜头；分镜输出 → 生成镜头。上游授权失效沿链传导到下游。

## 闸门规则（`src/`）

| 模块 | 职责 |
| --- | --- |
| `load.js` | 装载、结构校验、参照完整性（孤儿引用、派生图成环、团队跨专业、名额一致） |
| `provenance.js` | 发布版本逐层追溯：每项素材的引入版本、版本链段、素材级上游来源；成员贡献追溯 |
| `rights.js` | 五要素逐渠道核对；受限素材、许可缺失、撤回、被取代声明判定 |
| `ingest.js` | 内容指纹识别换名重复上传；并行修订分支及其未授权素材 |
| `anonymity.js` | 盲评送评前匿名核查（院校标识/署名/可辨识人声/元数据残留） |
| `gate.js` | 发布闸门：聚合全部检查，输出放行/阻断；每条阻断带 `right`（卡在哪项权利）与 `chain`（卡在哪段派生链） |

**内置业务原则**：

- 成员退出只更新 `status/left_on`，贡献、署名与已授予许可全部保留（`tm-07` 退出成员的配音在就业对接仍可用，商业推广仍需本人再确认）。
- 获奖**不自动扩权**：`wk-08` 盲评获奖后投商业推广仍被阻断，奖项备注明确荣誉不等于商用授权。
- 盲评期间身份泄露在**送评前**阻断（`wk-09`），不等到公开展示。
- 重复上传的副本不继承原素材许可（`wk-05` 换名重传未挂声明 → 阻断）。
- 许可到期（`wk-02`，2026-08-31 到期）、撤回并向派生镜头传导（`wk-03`）、受限档案混入公开版（`wk-04`）、分支配乐用途不足（`wk-06`）、续约收窄+主体存疑素材（`wk-10`）均逐部定位。

基准日（`registry.as_of`）驱动期限与撤回判定：同一作品在到期/撤回日前放行、之后阻断。

## 使用

```bash
npm test          # 21 项测试：契约、参照完整性、10 个阻断场景、批量闸门
npm run generate  # 重新生成确定性夹具
npm run report                 # 全部渠道 + 盲评匿名核查报告
npm run report -- ch-carnival  # 只看嘉年华
node scripts/gate-report.mjs ch-job wk-07   # 单部作品过闸
```

报告每条阻断形如：

```
· [素材权利/期限] 素材 as-02-mu
    声明 cl-02-mu 授权期限 2026-04-20 至 2026-08-31，基准日 2026-09-22 已到期
    派生链段：v-02-02 → v-02-03 → v-02-04
    许可声明：cl-02-mu
```

嘉年华批量结果（基准日 2026-09-22）：33 部中放行 27、阻断 6。

> 所有学生、团队、平台、机构与音乐库名称均为虚构，数据中不含真实个人信息或凭据；学生仅以编号入库。
